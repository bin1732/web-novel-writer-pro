# 矛盾节奏模板

> 段落长度控制 + 憋-释放模式 + 断裂留白 + 节奏切换 + 全篇节奏骨架

## 段落长度控制

### 核心原则
段落长度必须**不均匀**。AI的典型特征：每段4-6句，工整得像排版。真人写作则相反：有些段落长到停不下来，有些段落短到一个词。

### 量化标准
- ≥3个段落>5句（长段，展开描写）
- ≥3个段落≤1句（短段，一个词也行——"沉默。""不。"）
- 最长段/最短段字数比 > 3:1

### 目标分布

| 长度 | 占比 | 作用 | 典型场景 |
|------|------|------|----------|
| **1句段** | 15-20% | 点睛/反转/金句 | 高潮瞬间/对话冲突/情绪爆发 |
| **2-3句段** | 30-40% | 推进情节/对话 | 日常叙述/人物对话/动作描写 |
| **4-6句段** | 30-40% | 展开叙事/描写 | 环境描写/情感铺垫/世界观展示 |
| **7句+段** | 10-15% | 情绪高潮/动作场面 | 战斗/追逐/激烈对话/情感爆发 |

### 示例对比

**均匀段落（模板化痕迹）**：
```
他走进房间。房间里很暗。他打开灯。看到桌子上有一封信。
他走过去拿起信。信是湿的。他打开信封。
里面是一张照片。照片上的人是他自己。
但照片里的他，已经满头白发。
```
问题：每段3句，每段长度接近，节奏单调。

**不均匀段落（人味）**：
```
他推开门。
（没开灯，站了一会儿）
黑暗里能闻到一股潮湿的味道，像很久没人住过。他摸索着找到开关，按下去，灯闪了两下才亮。桌子上放着一封信，信纸边角卷起来了，像是被水泡过又被晾干的。

他拿起信。

里面滑出一张照片。

照片上是他的脸。一头白发，脸上的皱纹深得像刀刻的。他今年二十七岁。
```
效果：1句+3句+1句+1句+2句，节奏起伏，有真人写感。

## 憋-释放模式

### 原理
先制造紧张/期待（憋），再释放（爆发）。憋的时间越长，释放的爽感越强。不憋直接放→没有爽感。憋了不放→读者跑了。

### 三种周期

**短周期（单章内）**：
```
憋(前80%) → 释放(后20%)
憋: 铺垫、埋伏笔、制造期待
释放: 反转、爽点、高潮
```
示例：前8章铺垫主角被欺负→第9章结尾以隐藏身份震惊全场。

**中周期（3-5章）**：
```
憋(前3章) → 小释放(第4章) → 再憋(第5章) → 大释放(第6章)
```

**长周期（全卷）**：
```
憋(前70%) → 积蓄(中20%) → 释放(后10%)
```
整卷的高潮集中在最后10%的篇幅。

### 典型节奏范例

```
憋: 主角被欺负、被看不起 (2章)   ← 拉仇恨
蓄: 主角暗中准备、实力提升 (1章)  ← 造期待
放: 打脸逆袭、震惊全场 (半章)    ← 给爽感
余: 围观反应、后续影响 (半章)    ← 放大爽感
```

## 断裂式留白

### 原理
在关键处突然断掉或换话题，不让一切太"完整"。AI恨留白，真人爱留白。

### 五种技法

**1. 说到一半换话题**
```
"我想起来了，那天——"
他没说下去。窗外有什么东西吸引了注意。
```

**2. 用空行代替（切换场景或时间）**
```
"我们分手吧。"

（空行）

三个月后。
```

**3. 一个词成段（制造重量感）**
```
他举起剑。

沉默。

一剑。

对面的人倒下了。
```

**4. 答非所问（制造真实感）**
```
"你真的喜欢我吗？"
"外面下雨了。"
```

**5. 用动作中断对话**
```
"其实我一直想告诉你——"
她端起杯子喝了口水。
"算了，没什么。"
```

## 节奏切换信号

### 切换模式

| 切换方向 | 句子 | 段落 | 对话 | 描写 | 心理活动 |
|----------|------|------|------|------|----------|
| **慢→快**（紧张/高潮） | 变短 | 变短 | 变多 | 变少 | 变少 |
| **快→慢**（铺垫/过渡） | 变长 | 变长 | 变少 | 变多 | 变多 |

### 示例：慢→快切换

```
（慢：铺垫）
他沿着河边走了很久。水声很轻，像是怕打扰什么。芦苇被风吹得东倒西歪，有几根断在水里，顺着水流慢慢漂走。他看着那些断掉的芦苇，突然想到了很多年前——

（切换信号：一句短句）
他停住了。

（快：紧张）
前方的芦苇丛里有动静。不是风。那个动静太大了，而且正在往这边来。他握紧了手里的鱼叉。心跳声盖过了水声。芦苇分开了一条缝。他看到了——
```

### 节奏自检

- 连续3章"慢"节奏 → 读者要跑了，立刻补一个紧急事件
- 连续3章"快"节奏 → 读者会疲劳，补一段情感/日常缓冲
- 好节奏模式：快-中-中-快-中-慢-中-快
- 节奏变化频率：每2-3章变一次

## 每章节奏模板

### 标准章（2500-3500字）
```
开头(200-300字): 承接上文+快速进入主线 → 快
中段前(600-800字): 展开剧情/冲突 → 中快
中段后(600-800字): 铺垫高潮/深化 → 中
高潮(400-600字): 冲突爆发/爽点 → 快（短句短段）
结尾(200-300字): 钩子+收尾 → 慢-快（留悬念）
```

### 高潮章（3000-4000字）
```
开头: 直接进入状态，不铺垫 → 快
中段: 连续爽点/冲突升级 → 极快（句段最短）
高潮: 最高潮爆发 → 快中带停顿（一个词成段）
结尾: 强钩子+余波 → 快-慢（放慢节奏释放情绪）
```

### 过渡章（2000-2500字）
```
开头: 日常/铺垫 → 慢
中段: 信息揭示/人设深化 → 中
结尾: 暗示接下来有大事 → 中快
```

### 节奏检测清单

| 检查项 | 通过标准 | 失败处理 |
|--------|----------|----------|
| 段落均匀度 | 最长/最短比>3:1 | 打散均匀段落 |
| 节奏变化 | 每2-3章变化1次 | 调整章节情绪曲线 |
| 憋-放比例 | 憋:放≈7:3 | 太憋→提前释放；太放→加铺垫 |
| 留白数量 | 每章≥1处留白 | 加入断裂/空行/换话题 |
| 句长变异 | 短句(1-8字)占15-20% | 加入3个字以内的超短句 |
