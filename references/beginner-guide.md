# 新用户引导系统 · 引导模块

> 仅首次使用本 Skill 时触发。用户可选择关闭，关闭后永久跳过。
> **自然度优化引擎是本 Skill 的核心基础设施，所有模块共享，引导中可自动展示自然度优化速查卡（见 `anti-ai-engine.md`）**

```

本 Skill 帮你从零开始创作达到签约水准的网文小说。
固定工序流水线确保每一步都做到位，不遗漏关键环节。

支持：
✅ 拆解爆款作品、提取可复用模板
✅ 从你的文本中提取个人风格DNA
✅ 模仿66位知名作家风格创作（46中文+20英文）
✅ 从选题到签约正文的全流程创作
✅ 三管齐下自然度优化，写出自然流畅的原创内容

   推荐：自由设定 + 可关闭引导
```

### Step 2：学习偏好

```
你希望怎么了解本Skill？

🔍 快速上手（30秒）— 只看核心流程和触发词
   直接跳转"快速启动卡"

📖 详细教学（3分钟）— 完整了解每道工序
   逐工序展示说明

   遇到不明白的再问

### Step 3：展示快速启动卡

```
🚀 快速启动卡

想做什么 → 直接说：
--------------------------------------------------------------------

### Step 4：关闭引导确认

```
是否希望下次跳过引导？

👉 "下次不用引导了" / "关闭引导"
   → 永久跳过工序0，下次直接从工序1开始

👉 "先不关"
   → 下次仍然显示引导（但不会再次展示完整流程，只展示快速启动卡）
```

## 引导内容模板

### 快速启动卡（精简版）

为已看过一次但未关闭的用户提供：

```
📖 网文小说签约专家 1.0.3 · 快速参考

一句话触发：
"写个XX题材的小说，XX万字" → 直接开始

完整流水线（不可跳过）：
[1设定] → [2拆书] → [3蒸馏] → [4仿写] → [5创作] → [6润色] → [7签约]

常用指令：
"当前工序" → 查看进度
"跳过工序" → 跳过当前
"查看参考" → 读取参考文档
"关闭引导" → 永久跳过引导

支持自由设定：短篇(1-5万字) / 中篇(5-30万字) / 长篇(30-300万字)
支持中英双语自动切换
```

### 体验路线（供选择）

```
🎭 路线A：先看效果（5分钟体验）
   "用汪曾祺风格写一段市井日常" → 感受风格仿写精度
   
🎭 路线B：完整流程（推荐新人）
   "帮我写一本10万字的都市异能小说" → 从头到尾走完整工序

🎭 路线C：快速出稿
   "写个3000字的修仙爽文第一章" → 极速模式不走完整工序
```

## 引导关闭机制

| 关闭方式 | 触发词 | 效果 |
|----------|--------|------|
| 永久关闭 | "下次不用引导了" / "关闭引导" / "skip tutorial" | 当前轮次继续走完，后续永久跳过工序0 |
| 本轮跳过 | "跳过引导" / "直接开始" | 当前轮次跳过，下次仍然显示 |
| 恢复引导 | "重新开启引导" / "show tutorial" | 重新启用工序0 |

## 用户配置文件

引导完成后自动生成用户配置文件（保存到 skill 目录）：

```json
{
  "user_level": "beginner",     
  "tutorial_disabled": false,   
  "preferred_language": "zh",   
  "default_genre": "都市异能",
  "default_length": "medium",    
  "default_platform": "fanqie"
}
```

用户可在工序1中随时修改默认配置。
