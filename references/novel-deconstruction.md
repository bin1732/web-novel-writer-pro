## 拆书维度

### 1. 开篇模式分析

| 分析项 | 说明 |
|--------|------|
| 开头50字公式 | 前50字的写法模式 |
| 金手指觉醒方式 | 系统/血脉/重生/穿越/奇遇 |
| 第一个冲突类型 | 人际冲突/生存冲突/身份冲突 |
| 前3章结构模板 | 各章功能分配 |
| 第一章结尾钩子 | 钩子类型和强度 |

### 2. 章节节奏分析

| 分析项 | 说明 |
|--------|------|
| 平均每章字数 | 该类型爆款的字数区间 |
| 每章平均爽点数 | 爽点密度参考值 |
| 钩子类型分布 | 各类型钩子的使用频率 |
| 章节结构模板 | 爆款的章节内部结构 |
| 节奏曲线 | 全书的快慢节奏分布 |

### 3. 爽点分布分析

| 分析项 | 说明 |
|--------|------|
| 爽点类型偏好 | 打脸/升级/获宝/复仇/装逼的占比 |
| 爽点间隔 | 平均几章一个爽点 |
| 大高潮节点 | 第几章首次大高潮、间隔 |
| 压抑-释放比例 | 压抑段和释放段的长度比 |

### 4. 人物原型分析

| 分析项 | 说明 |
|--------|------|
| 主角类型 | 废柴/天才/重生者/穿越者/隐藏大佬 |
| 金手指类型 | 系统/功法/血脉/宝物/重生记忆 |
| 女主/男主类型 | 辅助型/独立型/对手型 |
| 反派设计 | 小反派/中反派/大反派的递进模式 |
| 配角功能 | 功能性配角如何分配 |

### 5. 常见雷区

该类型爆款作品中常见的失败原因：
- 开篇太平淡
- 金手指太无敌（失去悬念）
- 节奏太慢
- 人设崩坏
- 设定堆砌太多

## 执行流程

### 步骤1：确定拆书目标
- 根据工序1的题材选择，确定需要拆解的类型
- 如用户指定具体作品，优先分析该作品
- 如无指定，分析该类型3-5部代表性爆款

### 步骤2：模式提取
- 从开篇/节奏/爽点/人物四个维度提取模式
- 仅提取跨作品一致的共性模式
- 标注异常值（某部作品独特的打法）

### 步骤3：输出拆书报告
- 按上述模板结构填充
- 确保每个结论都有数据支撑
- 标注"建议参考"和"不宜照搬"

## 12项量化指标

| 指标 | 健康阈值 | 检测方法 |
|------|----------|----------|
| 前50字钩子强度 | ≥7/10 | 人工/模型判定 |
| 首章冲突出现位置 | 前500字内 | 文字定位 |
| 前3章爽点数 | ≥3个 | 爽点标注统计 |
| 平均章字数稳定性 | CV≤0.15 | 字数标准差/均值 |
| 对话占比 | 30-50% | 对话字数/总字数 |
| 每章结尾钩子 | 100% | 每章检查 |
| 连续无爽点间隔 | ≤3章 | 爽点分布图 |
| 金手指出现章节 | 第1-2章内 | 章节定位 |
| 第一个高潮章节 | 第3-10章内 | 章节定位 |
| 大高潮间隔 | ≤50章 | 高潮分布统计 |
| 主角出场时间 | 第1章前30% | 章节定位 |
| 设定说明单次长度 | ≤500字 | 段落字数统计 |

## 方法论卡片

从拆书结果中提炼可复用的创作方法论：

| 字段 | 说明 | 示例 |
|------|------|------|
| 方法名 | 简洁名称 | "三章情绪循环法" |
| 适用场景 | 什么情况下用 | "开篇节奏控制" |
| 操作步骤 | 具体怎么做 | Step 1-3 |
| 反例 | 做错了什么样 | "全程高潮没有铺垫" |
| 验证案例 | 哪部作品验证了 | "《斗破苍穹》第1-3章" |

## 四层榨取法（深度拆书）

| 层次 | 核心问题 | 产出 |
|------|----------|------|
| 骨架层(What) | 核心论点是什么？ | 定义+底层逻辑 |
| 肉质层(Why+How) | 为什么有效？ | 机制+案例三连 |
| 行动层(Action) | 我能怎么用？ | 执行SOP+迁移矩阵 |
| 批判层(Critical) | 有什么局限？ | 局限性+失效场景 |

**案例三连**：每个知识点配3个案例——原书案例+跨行业应用+生活场景。
**跨行业迁移**：至少3个行业的落地方式。

## 反常识挖掘

提取"与直觉相反"的认知翻转点：

**反常识写作公式**：
```
不是[常识认知]，而是[反常识真相]。
因为[底层逻辑]。你以为[表面现象]，其实[深层机制]。
```

## 写作问题诊断

当用户说"节奏太慢""开篇没人看""卡文了"时，自动匹配：

| 症状 | 可能根因 | 解决方案 |
|------|----------|----------|
| 开篇没人看 | 开头3段不抓人/前50字太平淡 | 重写开头：冲突开场/悬念开场/反转开场 |
| 节奏太慢 | 爽点间隔过长/描写过多 | 缩短描写段/提前第一个爽点 |
| 人物没记忆点 | 人设不够鲜明/金手指不够独特 | 给主角加标志性口头禅或动作 |
| 读者弃文 | 连续多章平淡/钩子不够强 | 每章结尾加强钩子/穿插小高潮 |
| 对话假 | 对话太书面化/不符合人物性格 | 增加口语化/让人物说话方式不同 |
| 设定吃书 | 前后设定矛盾/力量体系崩了 | 建立设定文档/每次写前查档 |
