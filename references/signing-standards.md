# 签约标准与写作技巧详细规范

> 签约级质量标准 + 作家风格库 + 前3章模板 + 人物设计 + 世界观 + 修改优先级
> 自然度优化规则请引用 `anti-ai-engine.md`

## 签约标准

### 书名标准
- 4-8字最佳，要有辨识度和记忆点
- 体现题材和核心卖点
- 避免生僻字和烂大街的命名（如"XX之XX"）
- 好书名让读者一眼知道题材类型

### 简介标准
**一句话简介**：15-25字，钩子十足，让编辑3秒内想看，必须包含核心冲突或悬念
**详细简介**：100-200字，结构：身份引入→困境展示→金手指揭示→冲突升级→悬念收尾

### 大纲标准
- 有明确主线和至少2条支线（情感线+成长线为标配，悬疑线可选）
- 每卷有独立高潮和转折，有伏笔和反转设计
- 14人命运卡：先于正文锁定核心角色的最终命运/关键抉择/结局场景
- 总字数：男频100-300万字，女频50-150万字（可自由调整）

### 正文标准
- 每章2500-3500字（按平台调整：番茄2200-2800，起点3000-4500）
- 开头3段必须抓人（悬念/冲突/反转/危机）
- 每章结尾必须有钩子（10种类型轮换使用）
- 对话占比30-40%
- 不能有大段无聊描写
- 节奏要快不能拖沓
- 每章必须有爽点设计

### 人物标准
| 要素 | 要求 |
|------|------|
| 金手指 | 必须有，类型明确（系统/血脉/重生/外挂等） |
| 性格 | 3个关键词概括，鲜明有记忆点 |
| 成长弧线 | 3个阶段，从弱到强有清晰路径 |
| 动机 | 核心动机明确，驱动全书行为 |
| 标志 | 口头禅或标志性动作，增强记忆点 |
| 语音指纹 | 口语/口头禅/句式偏好/禁忌用语/语气节奏 |
| 双层命名 | 关键角色配主名+本名，心理活动用本名/社会场景用主名 |

## 爽点设计公式

| 类型 | 流程 |
|------|------|
| **打脸爽** | 被看不起→展示实力→对方震惊→围观惊叹 |
| **升级爽** | 突破瓶颈→实力大增→碾压对手→获得奖励 |
| **获宝爽** | 意外发现→鉴定真伪→价值连城→众人羡慕 |
| **复仇爽** | 被欺负→隐忍变强→回来报仇→大快人心 |
| **装逼爽** | 低调出场→关键时刻出手→震惊全场→身份揭晓 |
| **救美爽** | 英雄救美→美人倾心→敌人嫉妒→实力确认 |

## 钩子设计

10种类型（悬念/危机/反转/情感/信息/身份/宝物/约定/预告/选择）
原则：同一类型不连用两次，每章结尾必须有钩子
详见 `hook-templates.md`

## 节奏控制

| 章节范围 | 节奏 | 核心任务 |
|----------|------|----------|
| 1-10章 | 极快 | 密集爽点，每章有爽点，让读者上瘾 |
| 11-30章 | 中快 | 铺垫情感和世界观，保持爽点密度 |
| 31-50章 | 加快 | 推向第一个大高潮，tension持续升高 |
| 50章后 | 循环 | 每50章一个大高潮，高潮间有铺垫但不拖沓 |

## 前3章详细模板

### 第一章（2500-3500字）
1. **开头(前3段，300-500字)**：悬念/冲突/反转/危机开场
2. **主角出场(500-800字)**：展示性格特质，建立读者认同
3. **危机呈现(500-800字)**：核心冲突建立，让读者为主角担心
4. **金手指觉醒(500-800字)**：外挂/系统/能力初次展现
5. **结尾钩子(200-300字)**：必须留悬念

### 第二章（2500-3500字）
1. **承接开头(300-500字)**：衔接第一章结尾钩子
2. **金手指初用(600-1000字)**：展示金手指的基本用法
3. **第一次小爽点(500-800字)**：小规模逆袭/获宝
4. **新冲突/悬念(500-800字)**：引入更大的挑战
5. **结尾钩子(200-300字)**：新悬念或危机

### 第三章（2500-3500字）
1. **承接开头(300-500字)**：衔接第二章结尾
2. **第一次正式逆袭打脸(800-1200字)**：完整打脸流程
3. **展示金手指威力(400-600字)**：让读者看到潜力
4. **引出更大世界观(400-600字)**：暗示更大世界
5. **新角色登场(300-500字)**：引入重要配角或反派
6. **结尾钩子(200-300字)**：更大的悬念

## 世界观构建标准

| 维度 | 要求 |
|------|------|
| **力量体系** | ≥5级，每级名称+特征+战力+突破条件 |
| **势力分布** | 各势力特点+实力+与主角关系+势力间关系网 |
| **压力系统** | 5维度：外部危险/内在伤口/团队摩擦/思想对手/拖延代价 |
| **世界地图** | 文字描述主要区域，标注关键地点 |

## 修改优先级分级

| 级别 | 含义 | 处理要求 | 示例 |
|------|------|----------|------|
| **S级** | 必须修，不改不交稿 | 立即修复 | 逻辑硬伤/人设崩坏/违规 |
| **A级** | 强烈建议修 | 修改后再进入下一步 | 节奏问题/爽点缺失/钩子不强 |
| **B级** | 修了更好 | 有时间再修 | 文笔优化/细节增强 |
| **C级** | 锦上添花 | 可选择不修 | 风格调整/创意增补 |
