# 跨媒体改编指导

> 小说 → 短剧 / 漫画 / AI有声书 / 游戏 改编全流程
> 版本: 1.0.3

---

## 一、短剧改编

### 格式规范
- 单集时长：1-3分钟
- 集数：60-100集（对标快手/抖音短剧标准）
- 总时长：60-300分钟
- 单集字数：剧本800-1500字

### 小说→短剧改编流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 核心冲突提取** | 从小说中提取可视觉化的核心冲突 | 内心独白→外在冲突转化 |
| **2. 人物精简** | 保留3-5个核心角色，其余合并或删除 | 配角过多会分散注意力 |
| **3. 场景拆分** | 将小说场景拆为1-3分钟独立场景 | 每场景必须有冲突+转折 |
| **4. 对白改写** | 小说叙述→短剧对白，信息量全部对白化 | 删掉心理描写，用行动/表情替代 |
| **5. 钩子强化** | 每集结尾必须有强钩子 | "下集更刺激"式悬念 |
| **6. 节奏压缩** | 小说10章内容→短剧3-5集 | 删掉过渡，只留冲突 |

### 短剧剧本格式

```
═══════════════════════════════════
第1集 「重生之夜」
═══════════════════════════════════

【场景1】办公室·夜
[氛围：压抑，暖黄台灯，文件堆积]
林晚（28岁，疲惫白领）伏案，手机震动。

林晚：（低声）妈，我加班...

【场景2】回忆闪回·三年前
[画面：婚礼现场，红色喜字]
前夫陈昊揽着新娘，林晚站在门外。

林晚（画外音）：我以为那是结束。

【场景3】医院走廊·现在
[氛围：冰冷，白色荧光灯]
林晚盯着手机——体检报告。

林晚：（捏紧手机）晚期...

═══════════════════════════════════
⚡ 钩子：她倒下时，一道光吞没世界——
   她睁眼，回到三年前婚礼当天。
═══════════════════════════════════
```

### 短剧平台适配

| 平台 | 单集时长 | 集数 | 风格偏好 | 签约要求 |
|------|----------|------|----------|----------|
| **快手短剧** | 2-3分钟 | 60-80集 | 逆袭/甜宠/复仇 | 星芒计划/光合计划 |
| **抖音短剧** | 1-2分钟 | 80-100集 | 悬疑/反转/甜宠 | 抖音剧情号签约 |
| **芒果TV短剧** | 3-5分钟 | 30-50集 | 言情/都市 | 大芒计划 |

## 二、漫画改编

### 格式规范
- 每话页数：12-20页
- 每页格数：4-8格
- 对白气泡：单气泡≤30字
- 旁白框：单框≤40字

### 小说→漫画改编流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 关键场景选取** | 从小说中筛选视觉冲击力强的场景 | 内心戏→视觉隐喻转化 |
| **2. 对白压缩** | 小说叙述→漫画气泡，信息密度3倍压缩 | 1段小说描写→1格画面+1句对白 |
| **3. 画面构图** | 为每格设计构图：远景/中景/近景/特写 | 节奏感：远景铺陈→近景冲突→特写情绪 |
| **4. 视觉节奏** | 格大小变化制造节奏 | 大格=重要时刻，小格=快速过渡 |
| **5. 留白设计** | 无字格/大空镜营造氛围 | 关键情绪点用留白强化 |

### 漫画分镜格式

```
═══════════════════════════════════
第1话 「雪夜孤行」 页1
═══════════════════════════════════

【格1】远景/大格
画面：雪中古栈道，一人独行
旁白：大隋末年，天下将乱

【格2】中景
画面：少年（林远）背柴，回望山门
林远：「我走了。」
老者（画外）：「莫回头。」

【格3】近景
画面：林远眼眶微红，嘴角紧抿
（无声）

【格4】特写
画面：腰间那块破旧玉佩
旁白：他不知道，这块玉——
═══════════════════════════════════
```

### 漫画平台适配

| 平台 | 风格偏好 | 更新频率 | 签约模式 |
|------|----------|----------|----------|
| **腾讯动漫** | 热血/玄幻/恋爱 | 周更1话 | 签约作者+分成 |
| **快看漫画** | 甜宠/青春/古风 | 周更2话 | 独家/非独家签约 |
| **哔哩哔哩漫画** | 日式/热血/冒险 | 周更1话 | 稿费+分成 |

## 三、AI有声书制作

### 格式规范
- 单集时长：8-15分钟
- 播放语速：1.2x-1.5x
- 情绪标记密度：每500字≥1个
- 角色声音标签：每个角色必须有独立标签

### 小说→AI有声书脚本流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 叙述者选型** | 选择TTS声音类型（男声/女声/中性） | 旁白声音≠角色声音 |
| **2. 角色声音标签** | 为每个角色分配TTS声音标签 | 主角/配角/反派声音必须有区分度 |
| **3. 情绪标记插入** | 在关键情绪转折点插入情绪标记 | [开心][悲伤][愤怒][紧张][平静] |
| **4. 停顿标注** | 场景切换/段落过渡/悬念处标注停顿 | [停顿1秒]/[停顿3秒]/[停顿5秒] |
| **5. 音效标注** | 环境音/动作音/背景音乐 | [风声]/[刀剑声]/[紧张BGM渐入] |
| **6. 节奏调优** | 长段落拆分，对话加速，描写减速 | 对话语速1.3x，描写语速0.9x |

### AI有声书脚本格式

```
═══════════════════════════════════
第1章 「重生之夜」
═══════════════════════════════════

[声音：女声-温柔旁白]
[背景：雨声+城市白噪音]
[情绪：平静]

林晚盯着电脑屏幕上的数字，
已经凌晨两点了。

[停顿1秒]
[情绪：疲惫]

加班。又是加班。

[声音切换：林晚-女声-年轻疲惫]
「妈，我今晚又不回来了...」

[声音切换：旁白]
[停顿2秒]
[背景音渐弱：雨声变小]

她不知道的是——

[情绪：紧张]
[背景：低频悬疑BGM渐入]

手机上的体检报告，
正静静躺在未读消息里。

[停顿3秒]
[情绪：沉重]

晚期。

═══════════════════════════════════
```

|------|---------|----------|----------|
| **喜马拉雅** | 自研TTS+AI配音 | VIP分成+广告 | 全品类 |

## 四、游戏化改编

### 格式规范
- 类型：视觉小说/文字冒险/叙事RPG
- 分支节点密度：每1000字≥1个选择点
- 结局数量：≥3个（好/中/坏）
- 角色好感度系统：核心角色必须有

### 小说→游戏改编流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 主线提取** | 小说主线→游戏主线剧本 | 主线必须保持，支线可自由扩展 |
| **2. 分支设计** | 在关键抉择点设计分支 | 每个分支必须有明确后果 |
| **3. 多结局框架** | 设计≥3个结局 | 好结局=读者满意，坏结局=有逻辑支撑 |
| **4. 好感度系统** | 核心角色好感度影响剧情走向 | 好感度门槛触发不同剧情线 |
| **5. 成就系统** | 里程碑事件设计成就 | 增加重玩价值 |
| **6. UI/UX适配** | 文字→游戏界面设计 | 对话框/选择框/状态栏/地图 |

### 游戏剧本格式

```
═══════════════════════════════════
场景：客栈大厅·夜
═══════════════════════════════════

[背景：古风客栈，灯火昏黄]
[角色：林远（主角）| 苏晚（好感度：60）]

苏晚靠在窗边，月光洒在她侧脸上。

苏晚：「你真的要走？」

[A] 「我必须去。」
    → 苏晚好感度-10
    → 进入【独闯剑阁】线

[B] 「...我再想想。」
    → 苏晚好感度+5
    → 进入【客栈夜话】线

[C] 「跟我一起走。」（需好感度≥80）
    → 苏晚好感度+20
    → 进入【双人组队】线
    → 解锁成就：「剑与花」
═══════════════════════════════════
```

## 五、版权与合同

### 改编权分类

| 权利类型 | 说明 | 注意事项 |
|----------|------|----------|
| **影视改编权** | 小说→电视剧/电影/短剧 | 通常单独授权，不包含在网文签约内 |
| **漫画改编权** | 小说→漫画/条漫 | 部分平台签约时自动获得 |
| **有声改编权** | 小说→有声书/AI有声书 | 多数平台签约时包含 |
| **游戏改编权** | 小说→游戏 | 高价值权利，建议单独谈判 |

### 分成模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **买断** | 一次性付清，作者不参与后续分成 | 新人作者/小体量作品 |
| **保底+分成** | 预付保底金+后续按比例分成 | 中等体量/有潜力的作品 |
| **纯分成** | 无保底，按收入比例分成 | 大IP/已有市场验证的作品 |
| **联合开发** | 作者参与改编创作，分享更大比例 | 作者有改编能力的情况 |

### 合同必查条款

1. 改编权范围（是否包含所有媒体形式）
2. 改编授权期限（几年？是否可续约？）
3. 分成比例（净收入vs总收入）
4. 创作参与权（作者是否有改编审批权）
5. 衍生品权利（周边/角色形象等）
6. 竞业条款（是否限制同类作品改编）
7. 回归条款（授权到期后权利是否回归作者）
8. AI改编条款（AI有声书/AI漫画是否包含在内）

### 平台改编规则速查

| 平台 | 有声权 | 漫画权 | 短剧权 | 游戏权 |
|------|--------|--------|--------|--------|
| **起点** | 签约含 | 单独授权 | 单独授权 | 单独授权 |
| **番茄** | 签约含 | 签约含 | 优先合作 | 单独授权 |
| **晋江** | 签约含 | 单独授权 | 单独授权 | 单独授权 |
| **盐言故事** | 签约含 | — | 优先合作 | — |

## 六、改编自检清单

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 核心冲突是否视觉化 | 可在1-3分钟内呈现 |
| 2 | 角色是否精简到位 | ≤5个核心角色 |
| 3 | 对白是否信息密度达标 | 短剧：每句≤20字；漫画：每气泡≤30字 |
| 4 | 钩子是否到位 | 每集/每话/每集结尾有悬念 |
| 5 | 版权是否清晰 | 改编权属/分成模式/授权期限已确认 |
| 6 | 平台适配是否完成 | 目标平台格式/风格/时长已适配 |
| 7 | 节奏是否压缩 | 无冗余过渡，纯冲突驱动 |
| 8 | 情绪节奏是否完整 | 起承转合在改编格式内完整 |
