# 感官细节库与感知层升温规则

> 感官描写五类详解 + 感知层升温量化规则 + 情绪×感官对应表 + 情感描写技法 + 感官偏心原则

## 感官描写五类

### 视觉

**基础层词库**：
- 颜色：泛白、发暗、发红、惨白、青灰、暗绿、昏黄、刺眼、灰扑扑
- 光线：昏暗、刺眼、朦胧、透亮、斑驳、闪烁、忽明忽暗
- 形状：模糊、清晰、扭曲、拉长、重叠、破碎、零散
- 动态：晃动、闪烁、流淌、翻涌、飘散、旋转、下坠

**增强层写法**：
- "阳光从窗帘缝里挤进来，在地板上拉成一条细细的金线"
- "他手上的青筋像蚯蚓一样凸起，一跳一跳的"
- "雨滴在玻璃上划出歪歪扭扭的痕迹，像在哭"

### 听觉

**基础层词库**：
- 环境：嗡嗡、沙沙、哗啦、滴答、啪嗒、咕嘟、嘶嘶、嘎吱
- 人声：低沉、尖锐、沙哑、颤抖、断断续续、含混不清
- 机械：轰鸣、嗡鸣、咔嗒、哐当、叮当、滴滴

**增强层写法**：
- "空调的嗡嗡声突然变得很响，像是有人把音量拧大了"
- "他的呼吸声在安静的房间里被放大了好几倍"
- "筷子碰到碗沿，发出一声清脆的'叮'"

### 触觉

**基础层词库**：
- 温度：烫手、冰凉、温热、刺骨、发冷、滚烫、淡淡的暖
- 质感：粗糙、光滑、黏腻、毛糙、软塌塌、硬邦邦、潮湿
- 触感：扎得慌、硌得疼、痒、麻、刺痛、酸胀、刺挠

**增强层写法**：
- "椅子的皮面破了个口子，露出里面黄黄的海绵，坐上去硌得慌"
- "他摸了摸自己的脸，胡茬扎手，像摸着一张砂纸"
- "杯子里的水已经凉透了，拿在手里像握着一块冰"

### 嗅觉

**基础层词库**：
- 食物：焦糊、酸臭、发馊、呛、香喷喷、油腻
- 环境：霉味、烟味、尘土味、潮湿味、消毒水味、樟脑味
- 人：汗味、香水味、烟味、酒味、药味、腥味

**增强层写法**：
- "一开门，一股泡面和汗味混合的味道扑过来"
- "空气里有股雨后的土腥味，混着不知谁家飘出来的葱花味"
- "他身上的烟味很重，像是刚从火场里出来"

### 味觉

**基础层词库**：
- 味道：酸、甜、苦、辣、咸、涩、腥、淡、鲜、麻
- 口感：硬、软、脆、韧、黏、滑、干、渣

**增强层写法**：
- "水是苦的。不是因为水质，是因为我现在的处境"
- "那口饭卡在喉咙里，咽不下去，也吐不出来"
- "茶泡得太久了，苦得发涩，但他还是一口一口喝完了"

## 感知层升温量化规则

### 核心规则
**每500字 ≥ 1处感知细节**。写完后逐段检查，缺则补入。

### 5类感知细节

| 类别 | 说明 | 示例（好） | 示例（不好） |
|------|------|------------|-------------|
| **身体感知** | 身体感受、生理反应 | "手心在出汗" | "他很紧张" |
| **情绪波动** | 情绪的身体表现 | "心跳漏了一拍" | "他很心动" |
| **生活碎片** | 日常生活中的感官 | "钥匙冰凉的触感" | "他回家了" |
| **认知过程** | 思考伴随的身体动作 | "他皱着眉头想" | "他在思考" |
| **主观判断** | 个人偏好的感受 | "这茶太苦了" | "茶的品质不佳" |

### 密度与情绪类型的关系

| 情绪类型 | 密度要求 | 主要感官通道 | 示例 |
|----------|----------|-------------|------|
| 紧张/恐惧 | 高（每200字1处） | 触觉+听觉 | "喉咙发紧""心跳声大得吓人" |
| 悲伤/失落 | 中高（每300字1处） | 触觉+味觉 | "手脚发凉""嘴里发苦" |
| 快乐/轻松 | 中（每500字1处） | 视觉+嗅觉 | "世界变亮了""闻到花香" |
| 愤怒/不爽 | 高（每250字1处） | 触觉+听觉+视觉 | "拳头握紧""耳朵嗡嗡""视野发红" |
| 平静/思考 | 低（每600字1处） | 视觉+听觉 | "看着窗外""听到钟声" |

| 情绪 | 主导感官 | 典型描写 |

## 情感描写五技法

详见 `emotion-recipes.md`，此处仅列要点：

### 1. 身体反应替写
不直接说情绪，写身体在做什么：
"他不安"→"他手指在桌上敲了三下，停住，又敲了两下"
"她紧张"→"她攥着杯子的手指泛白"
"他害怕"→"他喉咙发紧，半天没说出话"

### 2. 行为异常替写
该做的事不做，做反常的事：
该说话时沉默，该动时呆住，该哭时笑了一下

### 3. 细节放大法
聚焦一个极细微的细节写一整段：
"她盯着茶杯里的一根茶叶梗，看着它浮起来，又沉下去。浮起来，又沉下去。"

### 4. 沉默留白法
不写了，用空行代替：
"我们分手吧。"（空行）"他转身推门。风铃响了一声。"

### 5. 事后追溯法
事后才意识到当时的情绪：
"他当时没多想。后来在地铁上，他才意识到那一眼意味着什么。"

## 现成场景感官库

### 居家场景
- 掀锅盖：蒸汽糊眼、水汽扑脸、锅盖烫手
- 关冰箱：磁条"啪"地吸合、冷气扑面
- 洗碗：油腻的碗滑手、热水烫得指尖发红
- 起床：闹钟刺耳、被窝温暖不想动、脚踩地板凉
- 喝热水：玻璃杯烫手、水温刚好、一口下去暖到胃

### 办公场景
- 上班：弹窗消息惊得心咯噔、键盘空格磨得发亮
- 开会：空调太冷、椅子不舒服、咖啡凉了
- 加班：屏幕刺眼、脖子酸痛、走廊安静得吓人

### 通勤场景
- 地铁：刹车抓吊环晃身子、扫码手机卡顿3秒、人挤在一起热乎乎的
- 公交：窗户漏风冷飕飕、颠簸坐不稳、汽油味
- 走路：鞋磨脚后跟、风灌进领口、踩到积水脚凉了

### 消费场景
- 结账：看见余额愣住、店员问塑料袋迟疑
- 买菜：菜市场的各种味道混合、讨价还价声、手指触到蔬菜的湿润
- 吃饭：第一口烫到舌头、吃到一半才觉得辣、好吃的忍不住眯眼

## 感官偏心原则

### 核心原则
**不均匀分配感官类型，1-2种主导感官占总描写的50-70%。**

### 为什么？
AI的典型特征：均匀分配感官——视觉一段、听觉一段、触觉一段，工整得像教科书。
真人写作则不同：有人是视觉型（擅长画面描写），有人是触觉型（擅长身体感受）。
**偏心是活人感的来源。**

### 操作方法
1. 在写作前确定自己的主导感官类型
2. 主导感官描写的占比控制在50-70%
3. 其他感官合占30-50%
4. 最少使用的感官可以不写

### 快速自检
如果你的文本中五种感官的描写量大致相当 → 有模板化痕迹
如果你有1-2种明显偏爱的感官 → 更像人
