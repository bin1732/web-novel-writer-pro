## 一、AI辅助 vs AI代写：界限定义

### 核心原则

> **AI辅助 = 用AI做工具，人做创作者**
> **AI代写 = AI做创作者，人做编辑**

### 详细界限

| 维度 | AI辅助（合规） | AI代写（越界） |
|------|---------------|---------------|
| **构思** | 用AI头脑风暴/生成灵感关键词 | 让AI生成完整大纲 |
| **写作** | 用AI润色/检查/提建议 | 让AI写正文主体内容 |
| **修改** | 用AI找问题/提供修改方向 | 让AI重写段落（人仅微调） |
| **研究** | 用AI查资料/做背景研究 | 用AI生成世界观/设定 |
| **翻译** | 用AI做初译+人工精修 | 直接发布AI翻译结果 |
| **对话** | 用AI检查对话逻辑/角色一致性 | 让AI生成角色对话 |

### 判断标准：三个问题

1. **删掉AI的贡献后，作品是否仍完整？** → 是=辅助，否=代写
2. **核心创意是否来自人类？** → 是=辅助，否=代写
3. **最终文本是否经人类深度加工？** → 是=辅助，否=代写

### 本Skill的定位

本Skill设计为**AI辅助创作工具**：
- 自然度优化引擎 → 帮助人类写出更像人写的文字（辅助）
- 风格蒸馏 → 从人类文本中提取风格参数（辅助）
- 润色优化 → 提升表达自然度，让文本回归人味（辅助）
- 跨媒体改编 → 辅助改编方案生成，人类决策（辅助）

**不鼓励也不支持**：
- 让AI全文生成后仅做微调就发布
- 隐瞒AI参与程度欺骗平台和读者
- 用自然度优化技术掩盖AI代写事实

## 三、署名与声明规范

### 声明模板

**中文声明模板**：
```
本书创作过程中使用了AI辅助工具（如语法检查、灵感生成、润色建议），
所有正文内容均为作者独立创作完成。
```

**英文声明模板**：
```
AI-assisted tools were used during the creation of this work
(grammar checking, inspiration generation, polishing suggestions).
All content is independently written by the author.
```

### 声明放置位置

| 平台 | 推荐位置 |
|------|----------|
| 起点/番茄/晋江 | 作者的话/作品相关 |
| Amazon KDP | 上传时AI声明勾选+书内版权页 |
| Wattpad | 简介末尾 |
| 其他平台 | 作者简介/作品说明 |

### 声明原则

1. **诚实**：用了就声明，不用就不声明
2. **具体**：说明AI具体辅助了什么（润色/检查/灵感）
3. **适度**：不需要逐章声明，但需要整体声明
4. **主动**：不要等平台查到再补声明

## 四、AI辅助创作伦理边界

### 自然度优化技术的道德光谱

| 行为 | 性质 | 道德判断 |
|------|------|----------|
| 用AI辅助润色自己写的文字 | 创作工具使用 | ✅ 合规 |
| 学习AI痕迹特征以避免自身写作出现类似问题 | 技能提升 | ✅ 合规 |
| 用自然度优化技术处理AI辅助润色后的文本 | 工具叠加使用 | ✅ 合规 |
| 用AI生成全文后用自然度优化技术清洗 | 伪造原创 | ❌ 违规 |
| 用自然度优化技术掩盖AI代写事实 | 欺骗 | ❌ 严重违规 |
| 知道平台检测标准后故意绕开以发布AI代写内容 | 违规行为 | ❌ 严重违规 |

### 伦理边界

1. **不伪造原创**：AI代写的作品不是你的原创
2. **不欺骗读者**：读者有权知道作品的创作方式
3. **不绕开管理**：平台AI检测规则应被遵守而非绕开
4. **不侵犯版权**：AI生成内容可能存在版权风险

### 本Skill的自然度优化定位

本Skill的自然度优化引擎定位为**创作质量提升工具**，而非**AI代写伪装工具**：
- 帮助人类作者写出更自然、更有温度的文字
- 帮助润色后的文本达到人类写作的自然度
- 不帮助AI代写文本通过检测伪装成人类创作

## 五、版权风险

### AI生成内容的版权问题

| 问题 | 现状（2026） | 风险等级 |
|------|-------------|----------|
| **AI生成文本版权归属** | 目前尚无明确规定，倾向于不保护纯AI生成内容 | 🔴 高 |
| **AI辅助创作版权** | 中国：人类主导创作部分受保护 | 🟡 中 |
| **训练数据版权** | AI模型训练数据可能包含版权内容 | 🔴 高 |
| **同人创作与AI** | 使用AI生成同人内容版权风险更高 | 🔴 高 |
| **跨境版权** | 不同地区AI版权规则不同 | 🟡 中 |

### 版权风险防范

1. **保留创作过程**：保存大纲/草稿/修改记录，证明人类主导创作
2. **AI辅助不代写**：核心内容必须人类创作
3. **避免大段AI生成**：单次AI生成不超过100字，且必须人工修改
4. **声明AI使用**：主动声明降低后续纠纷风险
5. **了解平台条款**：不同平台对AI生成内容版权条款不同

### 特殊场景

| 场景 | 建议 |
|------|------|
| **AI生成角色设定** | 核心设定人工写，AI仅做补充建议 |
| **AI生成世界观** | 人类设计核心框架，AI填充细节 |
| **AI翻译后发布** | 必须人工精修，声明AI翻译 |
| **AI生成封面/插图** | 检查平台规则，多数平台要求声明 |

## 六、AI辅助创作最佳实践

### 创作流程中的AI使用建议

| 创作阶段 | 推荐AI使用方式 | 不推荐的方式 |
|----------|---------------|-------------|
| **选题** | AI分析市场趋势/热门题材 | AI生成选题直接使用 |
| **大纲** | AI辅助检查逻辑漏洞 | AI生成完整大纲 |
| **人设** | AI辅助检查角色一致性 | AI生成角色设定 |
| **正文** | AI润色/检查/建议 | AI写正文主体 |
| **修改** | AI检测问题/提建议 | AI重写段落 |
| **发布前** | AI检测AI痕迹/质量评分 | 用自然度优化技术掩饰AI代写 |

### 日常使用原则

1. **人机协作，人类主导**：AI是工具，不是作者
2. **透明声明，诚信为本**：用了就承认
3. **质量优先，不是追求低AI参与度**：目标是好作品，不是数字达标
4. **保留证据，保护版权**：保存创作过程记录
5. **持续学习，提升人工**：AI辅助是为了提升，不是为了偷懒
