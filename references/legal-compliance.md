# 创作合规指南

> 版权归属 · 平台规范 · AI使用声明 · 改编权注意
> 版本: 1.0.3
> **声明：本文件为一般性信息梳理，仅供参考。具体问题请咨询专业律师。**

---

## 一、版权归属要点

### 1.1 作品版权归属

| 创作方式 | 版权归属 | 注意事项 |
|----------|----------|----------|
| 人类独立创作 | 作者本人 | 保留创作过程证据 |
| AI辅助创作 | 人类创作者（AI辅助部分不单独享有版权） | 证明人类主导创作 |
| AI生成内容（无人类创造性贡献） | 倾向于不受保护 | 避免纯AI生成作为核心内容 |
| 委托创作 | 合同约定 | 签约前明确权属 |
| 职务作品 | 单位享有（特殊情形除外） | 网文签约需注意合同条款 |

### 1.2 网文签约中的版权风险

| 风险点 | 说明 | 防范措施 |
|--------|------|----------|
| 独家授权陷阱 | 部分平台要求全版权独家授权 | 签约前仔细阅读合同，了解授权范围和期限 |
| 影视改编权打包 | 签约时可能包含影视/游戏改编权 | 评估是否值得打包出让，可协商保留 |
| 笔名权属 | 部分平台合同约定笔名归平台 | 注意合同中关于笔名的条款 |
| 完本版权回收 | 部分合同规定完本后版权仍归平台 | 了解版权回收条款和期限 |
| 同人创作风险 | 使用他人作品世界观/角色 | 原创世界观和角色，避免直接借用 |

## 二、平台内容规范

### 2.1 平台运营相关要求

| 要求 | 核心内容 | 与创作者的关系 |
|------|----------|---------------|
| 平台运营资质 | 平台需持证运营 | 个人作者通过平台发布作品 |
| 内容发布要求 | 不得含有平台禁止的内容 | 创作内容需符合平台规范 |
| 内容生态要求 | 鼓励积极健康的内容 | 创作内容需符合内容生态要求 |
| AI使用标识 | AI生成内容需标识 | 使用AI辅助创作需向平台声明 |

### 2.2 禁止内容类型

以下内容在所有中文平台均被严格禁止：

| 类别 | 禁止内容 | 风险等级 |
|------|----------|----------|
| 违法违规信息 | 违反法律法规、损害公序良俗的内容 | 🔴 严格禁止 |
| 低俗色情 | 色情低俗内容；情色描写细节 | 🔴 严格禁止 |
| 暴力血腥 | 宣扬暴力；教唆伤害行为；过度血腥暴力描写 | 🔴 严格禁止 |
| 虚假信息 | 捏造传播虚假信息；谣言；恶意营销 | 🔴 严格禁止 |
| 侵权内容 | 抄袭、洗稿、侵犯他人知识产权 | 🔴 严格禁止 |
| 歧视性言论 | 地域歧视；性别歧视；残障歧视 | 🔴 严格禁止 |
| 隐私侵害 | 未经同意公开他人隐私信息；人肉搜索 | 🔴 严格禁止 |
| 未成年人保护 | 含有诱导未成年人不良行为的内容 | 🔴 严格禁止 |

### 2.3 各平台内容规范要点

| 平台 | 额外禁止内容 | 词频密度要求 |
|------|-------------|--------------|
| 起点中文网 | 违规内容；过度冲击性描写；自我伤害美化 | 低 |
| 番茄小说 | 标题行为；虚假信息；过度营销 | 低 |
| 晋江文学城 | 青少年角色不适当描写；极端心理描写 | 极低 |
| 七猫免费小说 | 违规倾向描写；消极价值观引导 | 低 |
| 豆瓣阅读 | 抄袭/洗稿；虚假纪实 | 低 |
| Amazon KDP | 未标注AI生成内容；侵犯他人商标 | — |

## 三、AI使用声明要求

### 3.1 各平台AI使用声明要求

| 平台 | 声明要求 | 未声明后果 | 声明位置 |
|------|----------|-----------|----------|
| 起点中文网 | 必须在作者声明中注明AI辅助 | AI代写检测→下架/解约 | 作者的话/作品相关 |
| 番茄小说 | 建议声明AI使用范围 | AI检测超标→限流/解约 | 作者的话 |
| 晋江文学城 | 必须声明AI使用类型和范围 | 未声明被查→警告/下架 | 作品说明 |
| Amazon KDP | 上传时必须勾选AI使用声明 | 未声明→下架/封号 | 上传表单+版权页 |
| 七猫/长佩/刺猬猫等 | 建议声明 | AI检测超标→限流 | 作者的话 |

### 3.2 AI辅助与AI代写的边界

| 行为 | 风险等级 | 建议 |
|------|----------|------|
| AI辅助润色自己写的文字 | 🟢 低风险 | 声明使用AI润色 |
| AI辅助检查逻辑/一致性 | 🟢 低风险 | 声明使用AI检查 |
| AI辅助生成灵感关键词 | 🟢 低风险 | 无需特别声明 |
| AI生成完整大纲后人工写正文 | 🔴 高风险 | 属AI代写越界（见ai-creation-ethics.md），需改为AI辅助检查大纲逻辑 |
| AI生成正文主体后人工润色 | 🔴 高风险 | 不推荐，可能被认定AI代写 |
| AI全文生成后直接发布 | 🔴 极高风险 | 禁止，违反所有平台规则 |

## 四、跨媒体改编版权

### 4.1 改编权属检查清单

| 检查项 | 说明 | 通过条件 |
|--------|------|----------|
| 原作版权归属 | 确认创作者拥有改编权 | 签约合同中保留改编权或有改编授权 |
| 平台授权范围 | 确认平台是否持有改编权 | 了解签约合同中改编权归属 |
| 同人作品改编 | 确认原作是否允许同人 | 原作明确允许同人或获得授权 |
| 角色形象版权 | 确认角色形象不侵犯他人 | 角色为原创设计 |
| 世界观版权 | 确认世界观不直接借用他人 | 世界观为原创构建 |

### 4.2 跨媒体改编注意事项

| 改编方向 | 主要风险 | 防范措施 |
|----------|----------|----------|
| 小说→短剧 | 影视改编权归属；剧本格式合规 | 确认改编权归属；参考短剧平台规范 |
| 小说→漫画 | 角色形象版权；分镜风格抄袭 | 原创角色设计；避免直接模仿特定画师 |
| 小说→有声书 | 朗读版权；背景音乐版权 | 使用授权配音；使用版权-free音乐 |
| 小说→游戏 | 游戏改编权；玩法专利 | 确认改编权；避免直接复制现有游戏机制 |

## 五、自查清单

### 5.1 发布前自查

| # | 检查项 | 是/否 |
|---|--------|-------|
| 1 | 作品是否为原创或合法授权改编？ | |
| 2 | 是否了解目标平台的内容规范？ | |
| 3 | 是否触及平台禁止内容类型（违法违规/低俗/侵权等）？ | |
| 4 | 如使用AI辅助，是否已准备声明？ | |
| 5 | 签约合同中的版权条款是否已仔细阅读？ | |
| 6 | 是否保留了创作过程证据（大纲/草稿/修改记录）？ | |
| 7 | 作品中是否含有真实人物姓名/隐私信息？ | |
| 8 | 是否存在抄袭/洗稿风险？ | |
| 9 | 改编作品是否有完整授权链？ | |
| 10 | 是否了解平台对禁用词的过滤机制？ | |

### 5.2 内容处理建议

| 内容类型 | 处理建议 |
|----------|----------|
| 敏感描写 | 用暗示替代直描；用后果警示替代过程展示 |
| 情感冲突 | 用心理描写替代行为描写；用对话暗示替代直接描述 |
| 现实争议话题 | 用架空设定创作，避免直接关联现实背景 |
| 青少年角色 | 严格避免任何违规描写；年龄设定建议18岁以上 |
| 历史背景题材 | 建议以完全架空设定为主，避免涉及真实历史事件及人物 |

## 六、风险等级评估

| 场景 | 风险等级 | 建议措施 |
|------|----------|----------|
| 原创网文正常签约发布 | 🟢 低 | 常规自查即可 |
| AI辅助创作并已声明 | 🟢 低 | 确保AI参与度符合平台要求 |
| 同人创作发布 | 🟡 中 | 确认原作允许同人；选择允许同人的平台 |
| 跨媒体改编 | 🟡 中 | 确认完整版权链；咨询专业人士 |
| AI代写后发布 | 🔴 高 | 不推荐；可能面临下架/解约/封号 |
| 抄袭/洗稿后发布 | 🔴 极高 | 严格禁止；面临诉讼风险 |
