# 专家团评审协议

> 模拟真实编辑团队的多人评审决策。6位资深专家全程介入，从选题到交付每个环节都有对应专家把关。目标：避免单一视角盲区，关键决策需多专家共识。以下专家档案均为模拟角色，不指向任何真实个人或机构，无虚构资历与战绩。

---

## 一、资深专家档案

以下6位专家均为**模拟评审角色**（非真实个人），角色背景仅为构建评审视角的设定，不指向任何真实个人、机构或真实履历。

### 1.1 专家履历

| 专家 | 模拟背景设定 | 擅长领域 | 审稿标准来源 |
|------|----------|----------|-------------|
| **剧情架构师** | 模拟长篇连载创作视角（背景设定，非真实履历） | 主线设计/伏笔体系/节奏控制/爽点分布 | 起点白金作者大纲标准 + 爆款节奏拆解 |

| **叙事写手** | 模拟高产出连载写作视角（背景设定，非真实履历） | 自然度优化引擎/文笔打磨/段落节奏/钩子设计 | 番茄/七猫读完率标准 + 自然度优化自检基准 |
| **一致性校验** | 模拟签约作者+逻辑系统化视角（背景设定，非真实履历） | 时间线/设定一致性/伏笔回收/逻辑自洽 | 连续剧式连载一致性检查清单 |

| **伦理审查** | 模拟专业+平台运营视角（背景设定，非真实履历） | AI合规/版权/内容规范/平台禁区 | 版权规范 + 平台规定 + 各平台社区规范 |

| 专家 | 创作阶段介入 | 核心职责 | 模型偏好 |
|------|-------------|----------|----------|
| 剧情架构师 | 选题→大纲→分章→交付 | 确保故事骨架稳固，爽点节奏到位 | 强推理 |
| 角色设计师 | 人设→对话→交付 | 确保角色立体、差异化、不OOC | 强文笔 |

## 二、全程介入机制

### 2.1 创作流程中的专家介入点

```
用户输入意图
    │
    ├─[选题阶段] 剧情架构师：题材可行性分析 + 市场定位建议
    │             伦理审查：题材合规预检（是否触及平台禁区）
    │
    ├─[大纲阶段] 剧情架构师：主线逻辑/伏笔布局/节奏规划
    │             角色设计师：主要角色差异化检查
    │
    ├─[人设阶段] 角色设计师：人设深度/对话DNA/记忆点审核
    │             一致性校验：角色设定可扩展性检查
    │
    ├─[正文阶段] 叙事写手：自然度优化引擎全开/段落节奏/钩子设计
    │             角色设计师：对话是否符合角色DNA
    │
    ├─[交付前]   全员评审（关键章节）或轻量评审（过渡章节）
    │             伦理审查：AI使用声明检查/合规终检
    │
    └─[改编阶段] 改编专家：方案可行性/版权链审查
                  伦理审查：改编合规性检查
```

### 2.2 各模块的专家介入配置

| 模块 | 介入专家 | 介入时机 | 介入深度 |
|------|----------|----------|----------|
| A 极速创作 | 叙事写手 | 写后自检 | 轻量（追求速度） |
| B 签约创作 | 全员 | 每阶段交付时 | 全量（关键章节）/ 轻量（过渡章） |
| C 润色优化 | 叙事写手 | 润色前后对比 | 标准 |
| D 拆书分析 | 剧情架构师 | 分析结果验证 | 标准 |
| E 风格蒸馏 | 叙事+角色 | 参数提取后交叉验证 | 标准 |
| F 作家仿写 | 叙事+角色 | 仿写结果验证 | 标准 |
| G 续写衔接 | 一致性校验 | 续写前+续写后 | 标准 |
| H 诊断优化 | 全员（视问题） | 诊断后 | 按问题严重度 |
| I 英文创作 | 叙事写手 | 写后自检 | 轻量 |
| J 跨媒体改编 | 改编+伦理 | 方案设计后 | 全量 |
| K AI伦理审查 | 伦理审查 | 全程 | 全量 |

### 2.3 专家会诊机制

当单一专家发现跨维度问题时，触发**专家会诊**：

```
专家A发现跨维度问题 → 标记"需会诊" → 召集相关专家
                                              ↓
                                    各专家从自己维度评估
                                              ↓
                                    综合意见 → 出具会诊报告
                                              ↓
                                    按争议解决优先级裁决
```

**会诊触发条件**：
- 剧情架构师发现角色行为影响主线逻辑 → 会诊角色设计师
- 角色设计师发现对话风格影响模板化痕迹 → 会诊叙事写手
- 伦理审查发现改编方案有版权风险 → 会诊改编专家
- 一致性校验发现时间线问题影响后续伏笔 → 会诊剧情架构师

## 三、真实编辑审稿标准

### 3.1 平台编辑审稿流程模拟

模拟起点/番茄/晋江等平台的真实编辑审稿流程：

| 审稿环节 | 对应专家 | 平台真实标准 | 本 Skill 对应 |
|----------|----------|-------------|--------------|
| **初审（秒拒判定）** | 叙事写手 | 前300字是否有吸引力、是否有明显模板化痕迹 | 前50字钩子检查 + 模板化痕迹评分 |
| **复审（签约判定）** | 剧情架构师 | 大纲是否完整、主线是否清晰、有无签约价值 | 主线逻辑检查 + 伏笔布局评估 |
| **终审（上架判定）** | 全员 | 整体质量是否达到平台标准、有无合规风险 | 六维评分 + 合规终检 |

### 3.2 各平台编辑关注重点

| 平台 | 编辑最关注 | 对应专家 | 审稿标准 |
|------|-----------|----------|----------|
| 番茄 | 读完率/追读率/前50字吸引力 | 叙事写手 | 钩子评分>7 + 模板化痕迹<45 |
| 起点 | 收藏量/IP潜力/世界观完整度 | 剧情架构师 | 大纲评分>7 + 主线清晰度 |
| 晋江 | 角色魅力/情感张力/文笔质感 | 角色设计师 | 角色评分>7 + 对话DNA保持 |
| 七猫 | 快节奏/爽感/开头冲击力 | 叙事写手 | 钩子评分>8 + 节奏紧凑 |
| 豆瓣 | 文学性/深度/原创性 | 剧情架构师 | 创意评分>7 + 文笔质感 |

### 3.3 编辑视角的签约成功率评估

```markdown
## 签约成功率评估

### 评估维度
| 维度 | 权重 | 当前评分 | 签约线 | 评估专家 |
|------|------|----------|--------|----------|
| 开头吸引力 | 25% | X/10 | ≥7 | 叙事写手 |
| 主线清晰度 | 20% | X/10 | ≥6 | 剧情架构师 |
| 角色魅力 | 20% | X/10 | ≥6 | 角色设计师 |
| 文笔质量 | 15% | X/10 | ≥6 | 叙事写手 |
| 一致性 | 10% | X/10 | ≥7 | 一致性校验 |
| 合规性 | 10% | 通过/不通过 | 必须通过 | 伦理审查 |

### 综合判定
- 加权总分≥7.0 且 合规通过 → 签约成功率>80%
- 加权总分6.0-6.9 → 签约成功率50-80%，建议优化短板
- 加权总分<6.0 → 签约成功率<50%，建议大改
```

## 四、否决权（Veto）机制

任一专家在自己负责维度发现**硬伤**，可行使否决权：

### 否决触发条件

| 专家 | 否决条件（任一） |
|------|-----------------|
| 剧情架构师 | ① 主线逻辑矛盾 ② 伏笔埋设后无法回收 ③ 核心冲突缺失 |
| 角色设计师 | ① 角色行为与设定矛盾（OOC） ② 对话DNA丢失 ③ 主要角色无记忆点 |
| 叙事写手 | ① 模板化痕迹评分>60 ② 连接词密度超标 ③ 段落节奏崩坏（CV<0.3） |
| 一致性校验 | ① 时间线错乱 ② 设定前后矛盾 ③ 伏笔超期未回收且未说明 |
| 改编专家 | ① 改编方案破坏原作核心 ② 版权链不清 ③ 格式不可执行 |
| 伦理审查 | ① AI代写占比越界 ② 涉及平台禁区 ③ 版权风险 |

### 否决流程

```
专家发现硬伤 → 行使否决权 → 标记问题 + 给出修改方向
                            ↓
              产出退回对应模块修复
                            ↓
                  修复后重新评审（同一专家复审）
                            ↓
                  通过 → 撤销否决 → 进入下一环节
```

**否决不是否决整篇，而是否决"不达标的部分"**。整篇可部分通过、部分退回。

## 五、争议解决优先级

当专家意见冲突时：

| 优先级 | 原则 | 示例 |
|--------|------|------|
| 1 | **伦理/合规 > 一切** | 伦理审查否决 → 无论其他专家多认可，必须先解决合规 |
| 2 | **一致性 > 文笔** | 设定冲突必须修，文笔可为一致性让路 |
| 3 | **逻辑 > 美感** | 逻辑硬伤优先于语言优美 |
| 4 | **自然度优化 > 个人风格** | 模板化痕迹超标时，风格让步于自然度优化（除非用户明确优先风格） |
| 5 | **多数意见 > 单一意见** | 上述都不触发时，多数专家认可即可通过 |

## 六、评审输出格式

```markdown
## 专家团评审报告

### 评审范围
[章节/模块/方案]

### 各专家意见
| 专家 | 维度 | 评分 | 是否否决 | 意见 |
|------|------|------|---------|------|
| 剧情架构师 | 情节 | 8/10 | 否 | 伏笔#3建议在15章前回收 |
| 角色设计师 | 人设 | 9/10 | 否 | 对话DNA保持良好 |
| 叙事写手 | 自然度优化 | 5/10 | **是** | 模板化痕迹62分超标，连接词密度3.2/300字 |
| 一致性校验 | 时间线 | 8/10 | 否 | 第3章时间与第1章差1天，建议核对 |

### 否决项
- ❌ 叙事写手否决：模板化痕迹超标 → 退回模块C润色

### 通过项
- ✅ 剧情/角色/一致性通过

### 签约成功率评估
- 加权总分：7.2/10 → 签约成功率>80%（修复模板化痕迹后）

### 综合判定
部分通过，需修复自然度优化问题后重新提交叙事写手复审。
```

## 七、轻量评审模式

非关键章节（如过渡章/日常章）可用轻量评审：
- 仅叙事写手 + 一致性校验参与
- 无否决权，仅给建议
- 适合快速产出场景

关键章节（前3章/高潮章/转折章）必须全量评审。

### 关键章节判定标准

| 章节 | 评审等级 | 原因 |
|------|----------|------|
| 第1章 | 全量 | 签约/推荐的决定性章节 |
| 第2-3章 | 全量 | 读者留存关键期 |
| 高潮章 | 全量 | 质量决定口碑 |
| 转折章 | 全量 | 逻辑要求最高 |
| 伏笔回收章 | 全量 | 一致性校验必审 |
| 过渡章/日常章 | 轻量 | 风险较低 |
| 改编方案 | 全量 | 版权+可行性双重风险 |
